# Renuka Telecom Android App

Android WebView wrapper project for the Renuka Telecom shop-management web app.

The GitHub Actions workflow installs JDK 17, Android SDK platform 35 and Build Tools 35.0.0, configures Gradle 8.9, builds the debug APK, verifies that the APK exists, and uploads it as the `RENUKA-TELECOM-APK` artifact.
